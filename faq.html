Editor Guida FAQ

Domande frequenti

I miei dati vengono caricati da qualche parte?

No. VascaLab funziona interamente nel tuo browser: il file .fit viene letto, modificato e riscritto sul tuo dispositivo. Non c'è nessun server, nessun upload, nessuna copia salvata altrove.

Perché Garmin Connect mostra ancora "sconosciuto" dopo la modifica?

Di solito succede per una di queste ragioni:

1) Stai ricaricando un file diverso da quello appena scaricato (magari una scheda del browser rimasta aperta con una versione vecchia dell'editor, o un file salvato in precedenza).

2) Garmin Connect non ha ancora cancellato la vecchia attività: cancellala prima di ricaricare quella corretta, altrimenti alcuni browser/schede mostrano la versione in cache.

3) Se il problema persiste, scarica di nuovo il file dall'editor e controlla che appaia il messaggio verde di conferma al caricamento.

Cosa succede alla frequenza cardiaca quando modifico una vasca?

La FC media/massima di sessione e delle vasche esistenti resta quella originale, perché è calcolata dal flusso di dati grezzi del cardiofrequenzimetro, che l'editor non tocca mai. Solo quando crei una vasca nuova (es. trasformando un riposo in attivo) VascaLab calcola la FC di quella specifica finestra temporale direttamente dai dati grezzi — non la inventa.

Posso modificare anche corsa, ciclismo o altri sport?

No, per ora VascaLab lavora solo su nuotate in vasca (pool swim), perché la logica è specifica per i length e i lap che questo tipo di allenamento usa. Altri sport non hanno questa struttura.

Il file corretto funziona anche su Strava o altri servizi?

Sì: il file resta un .fit standard e valido. Puoi caricarlo ovunque accetti file FIT, non solo su Garmin Connect.

Posso annullare una modifica?

Non c'è un tasto "annulla": se sbagli, ricarica di nuovo il file .fit originale nell'editor e riparti. Per questo è una buona idea tenere sempre da parte l'esportazione originale di Garmin Connect.

Funziona da telefono?

Sì, la pagina è responsive e usa solo funzioni standard del browser (lettura file, download). Su alcuni browser mobile il passaggio "trascina il file" non è disponibile: usa il pulsante per selezionarlo dalla galleria/file.

È sicuro modificare un file FIT?

Sì per l'uso previsto (correggere errori di registrazione). Ricorda però che stai modificando dati storici di un allenamento realmente svolto: usa l'editor per correggere ciò che il dispositivo ha registrato in modo sbagliato, non per alterare artificialmente le tue prestazioni.

Perché due vasche identiche a volte hanno durate leggermente diverse dopo un'unione?

Perché la durata unita è la somma esatta (al millisecondo) delle vasche originali — se vedi arrotondamenti è solo nella visualizzazione (es. "0:52" invece di "0:52,3"), il dato salvato nel file resta preciso.
